# TechStore API

API REST CRUD de productos desarrollada con Spring Boot, PostgreSQL, JWT y Docker.

## Tecnologías utilizadas
* Java 17
* Spring Boot
* Spring Security (JWT)
* PostgreSQL
* Docker & Docker Compose
* Maven
* Postman

## Guía de Instalación y Ejecución

### 1. Clonar el repositorio
Para obtener una copia local del proyecto, ejecuta:
```bash
git clone [https://github.com/GabBerma/TechStore-API.git](https://github.com/GabBerma/TechStore-API.git)
cd TechStore-API
